# 三篇の改訂版を出す時期

2026-11-12 に、二つの段に分ける計画を採りました。改訂版は、まだ出していません。

三篇の PDF は凍結しています（決めごと 2）。
紙面の誤りと欠落は、[正誤表](../ERRATA.md)に積んできました。
この頁は、正誤表にたまった分を本文に反映した改訂版を、いつ、どの形で出すかの計画です。
三篇の PDF と `papers/*.md` には、手を入れていません。

## 改訂版の位置づけ

公開済みの PDF は差し替えません。
改訂版は、新しい PDF として別に出します。
いまの PDF は、いまの正誤表と一緒に残ります。

Zenodo では、同じ記録の新しい版として出す形が考えられます。
版を作るのは著者です（決めごと 12）。
DOI は、著者から受け取ってから書きます。

決めごと 15 のもとで、改訂版は既存の三篇の修正として扱います。
新しい主題や新しい主張を足す場にはしません。
出す場は、決めごと 14 のとおり、ダイヤモンド・オープンアクセスの場に限ります。

段 2 は論証に触れる版です。
— は、改訂版で直すものが無い項目です。

## 二つの段に分ける

段 1 は、論証に触れない版です。
読者が PDF だけを手にしても正本と開示に辿り着けるように、表紙と開示文と参考文献欄を直します。
典拠を読む進み具合を待つ理由がありません。
三篇をまとめて出します。

段 2 は、論証に触れる版です。
典拠を読まずに書き直せば、E6 と E7 と同じことを繰り返します。
だから時期を日付ではなく、典拠の確認の進み具合で決めます。
条件は篇ごとに置きます。

| 篇 | 段 2 を出す条件 |
| --- | --- |
| 独身論 | 第4節が拠る典拠（エピクロス、ショーペンハウアー）の確認が、一致か不一致かに決まったとき |
| 皇帝主義 | 動員の層が拠るユンガーの典拠（`M-junger-1930`、`M-junger-1932`）の確認が決まったとき |
| 断章論 | 五輪書の箇所（`F-musashi-1645`）が指せたとき。または N8 の物語論の文献を読んだとき |

確認が「不一致」に決まった場合も、条件は満たされます。
そのときの改訂版は、典拠に合わせて主張を弱めるか、典拠を外すことになります。
弱めた主張が典拠なしでも立つなら弱め、立たないなら典拠と一緒にその主張を外します。

## 選ばなかった案

改訂版を出さず、正誤表だけを積む案があります。
凍結は保たれます。
ただし PDF だけを手にした読者は、E1・E5・E7 を知らないままになります。

すべてを一度に直す案もあります。
その場合、E6 が解けるまで表紙の欠落も残り続けます。

日付で決める案もあります。
段 1 には合います。
段 2 には合いません。典拠を読む進み具合と関係なく、その日が来るからです。

## 改訂版を出すときの段取り

1. 正誤表の項目ごとに、改訂版でどう扱ったかを並べた対応表を作ります。
2. 改訂した本文から、新しい PDF を作ります。いまの PDF と `papers/*.md` は残します。
3. Zenodo の新しい版は、作業環境からは作れません（決めごと 12）。DOI は、受け取ってから、このリポジトリに書きます。
4. 正誤表の各項目に、改訂版で反映したことを書き足します。いまの PDF については解決しないので、項目は消しません。
5. 新しい PDF を `verification/check_fidelity.py` と `verification/check_errata.py` の対象に加えます。いまの PDF の SHA-256 は変えません。
6. 改訂版にも、言語モデルの利用の開示を置きます。翻訳と照合を誰が行ったかを書きます。

## 決めたこと

2026-11-12 に、次のとおり決めました。

- 二つの段に分けます。段 1 は典拠を読む進み具合を待たずに直せ、段 2 は待たなければ E6 を繰り返すためです。
- 段 1 は、段 2 を待たずに出す版とします。
- 段 2 を出す条件は、上の表のとおりとします。
- 改訂版の英文にも言語モデルを使います。開示の文面は、E5 の扱いの欄に書いた中身に、使った道具の名を足したものとします。いまの三篇の英文も言語モデルによるもので、扱いを変えると本文の調子が版の間でずれるためです。

改訂版は、段 1 も段 2 も出していません。
Zenodo に新しい版を出すことは、作業環境からはできないためです。

# デザインに関する法的な扱い

## この頁について

この頁は、このサイトの見た目の部品について、誰が作り、どこから来て、権利と許諾がどうなっているかを書きます。
部品とは、書体、サイトの名の表示、アイコン、図と画像、配色、配置、外から読む素材のことです。
三篇の論文の PDF（`pdf/`）は、凍結した紙面です。
PDF の中の意匠は、この頁の対象に入れていません。

この頁は、運営者の側の理解を書いたものです。
法的な助言ではありません。
弁護士の確認は受けていません。

条の文は、e-Gov 法令 API から 2026-11-22 に取り寄せた写しのとおりに引きます。
記憶からは書いていません。
言い換えた文を、条の文とは呼びません。
写しの出所（取り寄せたリポジトリ、コミット 85dd680、見張りの実行の番号）と各条の SHA-256 は、[verification/design-statutes.json](../verification/design-statutes.json) に置いています。
出所のリポジトリの名を、この頁には書いていません。
研究の系列の頁には、そのリポジトリの名を書かないと決めているためです。

この頁は 2026-11-22 に Claude が書きました。
利用者が、すべてのサイトに、デザインに関する法的な扱いの頁を一つずつ求めたためです。

## 書体

このサイトは、書体のファイルを一つも配りません。
`assets/style.css` に `@font-face` がなく、外の書体を読む `@import` も `url(` もありません。
CSP は `default-src 'none'` で、`font-src` を置いていません。
ブラウザは、どこからも書体のファイルを読みません。

`font-family` の並びは、次の四つです。
並びの中の名は、閲覧する人の端末にある書体を名指すだけです。
端末に無い書体は飛ばされ、その次の名が使われます。

- 本文：`"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic", system-ui, sans-serif`
- サイトの名：`"Hiragino Mincho ProN", "Yu Mincho", "Noto Serif JP", Georgia, serif`
- 頁の題（h1）：`"Hiragino Mincho ProN", "Yu Mincho", Georgia, serif`
- コード：`ui-monospace, SFMono-Regular, Menlo, monospace`

書体を配っていないので、書体の許諾の条件はこのサイトに掛かりません。
端末の書体の許諾は、その端末の利用者と書体の権利者のあいだのことです。

## 見やすさ

障害を理由とする差別の解消の推進に関する法律（以下、障害者差別解消法）を引きます。

`障害者差別解消法 第2条` の第7号を切り出して引きます。

> 七 事業者 商業その他の事業を行う者（国、独立行政法人等、地方公共団体及び地方独立行政法人を除く。）をいう。

`障害者差別解消法 第8条` の全文を引きます。

> （事業者における障害を理由とする差別の禁止） 第八条 事業者は、その事業を行うに当たり、障害を理由として障害者でない者と不当な差別的取扱いをすることにより、障害者の権利利益を侵害してはならない。 ２ 事業者は、その事業を行うに当たり、障害者から現に社会的障壁の除去を必要としている旨の意思の表明があった場合において、その実施に伴う負担が過重でないときは、障害者の権利利益を侵害することとならないよう、当該障害者の性別、年齢及び障害の状態に応じて、社会的障壁の除去の実施について必要かつ合理的な配慮をしなければならない。

運営者がこの法の「事業者」に当たるかは、条の文からは決まりません。
この頁は、当たるとも当たらないとも決めません。

当たるかどうかに関わらず、このサイトがしていることを次に書きます。
どれも、このリポジトリの検査が確かめている事柄です。

- 文字の色が、地の色に対して WCAG の 4.5:1 以上あります。ライトとダークの両方で、`check_site.js` が比を計算します。
- 暗い配色は、端末の設定と、切り替えの釦の両方に従います。二つは同じ色を使います（`check_site.js`）。
- 本文の中のリンクは、色のほかに下の線で示します（`check_site.js` の 11）。
- 動きを減らす設定（`prefers-reduced-motion: reduce`）では、色の移り変わりをほぼ無くします（`check_site.js` の 11）。
- どの頁にも画像がありません。代替の文が要る画像が無いことを、`check_site.js` の 11 が確かめます。
- どの頁にも、本文へ飛ぶリンク（本文へスキップ）があり、言語を `ja` と書きます（`check_site.js` の 11）。
- キーボードの Tab で頁を辿り、焦点の枠が出ること、焦点が先へ進むこと、辿る順が読む順と同じことを、`check_keyboard.js` が確かめます。
- 文字を 200% にしたときと、狭い画面の幅で、頁が横へはみ出さないことを、`check_keyboard.js` が測ります。

この一覧の検査は、読み上げの道具で聞いて確かめるものではありません。
読み上げで聞いたときの分かりやすさは、確かめていません。

## 変わったとき

見た目の部品を変えるときは、同じ PR で、この頁と `check_site.js` の 11 を直します。
`check_site.js` の 11 は、部品の一覧、書体の並び、ライセンスの表、見やすさの事柄、条の文を、`site/` と `assets/` と `verification/design-statutes.json` から数え直します。
この頁の書いたことと食い違えば、落ちます。

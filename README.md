# 自律と自己陶冶

種類：エッセイ　状態：凍結

[![照合](https://github.com/cpsbvbng26-dotcom/autonomy-and-self-cultivation/actions/workflows/verify.yml/badge.svg)](https://github.com/cpsbvbng26-dotcom/autonomy-and-self-cultivation/actions/workflows/verify.yml)

**自分の生をどこまで自分で治められるか**を主題にした、三篇のプレプリントを収めたリポジトリです。

一篇は独身（celibacy）を、性的活動の欠落ではなく擁護しうる自己陶冶の型として読み直します。
一篇は、断片化した自己を統合する試みを「人格的帝国主義」という概念のもとで素描します。
残る一篇は逆に、断片化を修復すべき傷ではなく生の実際の姿として受け取り、そこに住まうための規律を組み立てます。

主題は離れて見えますが、問いは共通しています —— **何を基準に、自分の生の形を決めるのか**。
統合を目指す二篇目と、統合を諦める三篇目が並んでいるのは、矛盾ではなく問いの幅です。

三篇とも査読前の原稿です。著者による公開は Zenodo で行っています。SSRN にあるのは二篇です。所在は下の「公開先」の表にあります。
このリポジトリは**全文を読める形に開き、版と出典をひとところに置くため**のものです。

## 三篇

### [The Nobility and Exemplarity of the Celibate Individual](papers/celibate-individual.md)

*An Antinatalist and Ascetic Reconsideration of Autonomy and Quality of Life* — v2, 2026年8月22日

性的活動を倫理的に必要とみなす通説は、生殖がなければ社会は存続しないという事実から個人の義務を
導いています。この論文は、その移行が反出生主義の議論を前に持ちこたえないことを示したうえで、
エピクロスの快の区別とショーペンハウアーの意志の形而上学を手がかりに、他者や欲望の周期に
依存しない自足的な幸福という観点から独身を積極的に評価します。

平易に三行で書きます。

- 独身を、性的な活動が欠けた状態ではなく、仏教・キリスト教・古典哲学に前史のある倫理的な選択として読み直します。
- 「生殖がなければ社会が続かないから性的な活動は義務だ」という考えは、生物の事実から倫理の義務を導いており、そのままでは成り立たないと論じます。
- そのうえで独身を、他人や欲望の波に左右されない安定した幸福を育てる、手本になりうる生き方の一つとして擁護します。

### [Manifesto of Imperial Selfhood](papers/imperial-selfhood.md)

*An Exploratory Essay on Personal Imperialism and Spiritual Sovereignty* — 改訂版, 2026年8月

カントの「目的の王国」から立法の層を、ニーチェの力への意志から評価の層を、ユンガーの
「労働者のゲシュタルト」から動員の層を取り、三層構造として組み立てます。眼目は、三者を
滑らかに統合しないところにあります。普遍主義と遠近法主義の緊張こそが構造の中身である、と論じます。

平易に三行で書きます。

- ばらばらになった自分を、自分の内側で一つの秩序にまとめる企てを、人格的帝国主義と名づけます。ここでの帝国は国家でも他人の支配でもありません。
- 材料は三人です。自分で法を立ててそれに従うカント、価値を作り直し続けるニーチェ、持てる力を残らず形にするユンガーです。
- 三つは互いに噛み合いません。その緊張を欠陥ではなく中身として抱えると論じ、「帝国」という語が外へ漏れる危うさを最大の未解決問題として残します。

## 三篇の骨格

論証が通っているかと、典拠を読んだかは、別の問題です。前提から結論への運びは、
原典を読まなくても検査できます。だから骨格を出します。

骨格を出すと、[`ERRATA.md`](ERRATA.md) の `E6`（引用した原典に著者は当たっていない）が
**どの関節に入っているか**が見えます。前提ごとに印をつけました。

- **措定** —— 典拠に依存しません。論文が条件として置いているもの
- **依存** —— 典拠に乗っている前提

依存は、さらに三つに分かれます。外れたときに残るものが違います。

| | |
| --- | --- |
| **確認済み** | その典拠を読んでおり、述べていることと一致した（`references.toml` の `agreement`） |
| **自前** | 着想が先にあり、典拠は後から結び付けた。外れれば支えを失うが、前提は残る |
| **外から** | 着想が典拠から来た。**外れれば前提そのものが残らない** |

この三つの内訳は `ERRATA.md` の `E6` にあり、件数は機械が数えています。

### 独身論

| | |
| --- | --- |
| P1 | 性的活動を義務とみなす通説の根拠は、人口の維持である（**措定**） |
| P2 | 新たな生を生むことに無条件の価値はない（**依存・確認済み** —— Benatar。邦訳で読んでおり、紙面の述べる非対称性と一致した） |
| **C1** | ゆえに人口の維持は、個人に生殖の義務を課す根拠にならない |
| P3 | 他者や欲望の周期に依存しない種類の幸福がある（**依存** —— Epicurus の katastematic） |
| P4 | 性的欲望は個体の幸福ではなく種の存続に奉仕する（**依存** —— Schopenhauer） |
| **C2** | ゆえに独身は、自足的な幸福の型として擁護できる |

射程。C2 は範例（exemplary）であって普遍的な義務ではない、と第5節が明示しています。

関節の弱いところ。C1 は**生殖**を撃ち、C2 は**性行為**を撃ちます。避妊がこの二つを
切り離すので、**C1 は C2 を支えません**（`ERRATA` の `N5`）。C2 は P3・P4 だけで立ちます。

E6 の入り方。C1 は P2 に、C2 は P3・P4 に乗っています。
**C1 の依存は解けています** —— P2 の典拠は読んであり、一致しました。
C2 は解けていません。P3・P4 はどちらも未読です。結論二つのうち一つが、
まだ未読の典拠二つに乗っています。

### 皇帝主義

| | |
| --- | --- |
| P1 | 後期近代の自己は断片化している（**措定** —— 論証せず条件として置く） |
| P2a | 立法の層。自己が自己の法の立法者であり、同時にその法に従う者である（**依存・自前** —— Kant） |
| P2b | 評価の層。価値を定め直し続けることが自己の運動である（**依存・自前** —— Nietzsche） |
| P2c | 動員の層。能力が余さず一つの形へ動員される（**依存・外から** —— Jünger） |
| P3 | 三層は互いに整合しない。普遍主義と遠近法主義、安定と恒常的な価値転換 |
| **C** | その不整合を欠陥ではなく、構造の中身として引き受ける |

射程。反照的のみ（strictly reflexive）です。他者への支配を含まない、と冒頭が明示しています。

典拠から独立して立つもの。C は、三層の内容が正しく読めているかとは別の主張です。
**「整合しない源泉を、整合させずに組む」という組み方についての主張**であり、
Kant の読みが誤っていても、組み方の是非は独立に判定できます。ここは E6 の外にあります。

関節の弱いところ。三層のうち一つが支配することを防ぐ機構を示していません。

E6 の入り方。三層のうち、立法と評価は着想の側が先にありました。目的の王国も意味の帝国も、
原典を読む前から著者の手にあり、カントとニーチェは後から結び付けた名です。
動員だけが違います。総動員という枠組みは典拠の側から来ました。
だから Kant や Nietzsche の読みが外れても P2a・P2b は支えを失うだけで層は残るが、
ユンガーの総動員が外れれば P2c は前提ごと残りません。
三篇のうち、前提が丸ごと未読の典拠に乗っているのはここだけです。

第4節の典拠（エピクテトス、マルクス・アウレリウス、デヴィッドソン）も自前です。
外から来ているのは、動員の層ひとつだけです。

### 断章論

| | |
| --- | --- |
| P1 | 生・信仰・社会・思想・終末は、連続した物語ではなく独立した断片である（**措定**） |
| P2 | 近代の合理主義・制度宗教・物語的自己・資本主義的自己実現は、共通の構造をもつ。**どれも単独で非連続な個人を、外部の連続性の論理に従属させる** |
| **C** | ゆえに断片化は修復すべき傷ではなく、そこに住まうための規律の対象である |

六つの断片（孤独・制度からの離脱・思想と鍛錬の融合・反近代の美学・終末と栄光・系譜）が、
その規律の中身です。

典拠から独立して立つもの。P2 は分析であって引用ではありません。**四つの立場に共通の
構造を指摘する主張**であり、Kierkegaard や吉本隆明の読みが誤っていても、
その指摘が当たっているかは独立に判定できます。ここも E6 の外にあります。

### 骨格を出して分かること

E6 は周辺の飾りではありません。論証の関節に入っています。独身論の C2 は未読の典拠二つに
乗っており、そこは典拠を読むまで動きません。皇帝主義の P2c は、前提そのものが典拠の側から
来ています。

読むだけでは解けません。断章論の五輪書は、著者が原典を読んでいながら依存が解けていない唯一の例です。
論文の主張を支える巻を指せないからです。
解くのに要るのは読書ではなく、どこがどれを支えているかを書くことです。

そして、入り方は一様ではありません。独身論の C1 は典拠を一冊読んだだけで依存が解けました。
皇帝主義の P2a・P2b は、外れても層が残ります。P2c だけが、外れれば残りません。
一冊読むことの効き方が、関節ごとに違います。

同時に、E6 の外に立つ主張が二つあります。皇帝主義の C（整合しない源泉の組み方）と、
断章論の P2（四つの立場に共通の構造）です。この二つは、原典を読んでいなくても
成否を判定できます。判定に要るのは典拠ではなく、主張そのものへの反論です。

どちらも書いておきます。片方だけを出せば、片方は宣伝になります。

### なぜ Markdown も置くのか

PDF は体裁を固定できるが、本文を引用しようとすると行が割れ、検索にもかかりにくく、
版のあいだの違いも見えません。同じ本文を Markdown でも置いておくと、節の見出しに直接リンクでき、
`git diff` で改訂の中身がそのまま読め、全文検索も効きます。**PDF が配布物、Markdown が読むための形**、
という役割分担です。

本文は PDF から起こしたもので、書き写したものではありません。抽出した語の並びと照合しています。
下の数字は、書き写した値ではありません。[`verification/check_fidelity.py`](verification/check_fidelity.py)
を実行すると出ます。

| | PDF の語数 | 一致 | 食い違い | 内訳 |
| --- | --- | --- | --- | --- |
| 独身論 | 3696 | 3696 | なし | — |
| 人格的帝国主義 | 4302 | 4294 | 4 箇所 | ハイフン語の結合 4 |
| 断章論 | 5147 | 5131 | 8 箇所 | ハイフン語の結合 4、括弧内の余分な空白 4 |

数えているのは **Abstract 以降**です。冒頭の書誌表と日本語の要旨はこのリポジトリのために
書き下ろしたもので、原文にはないため、照合の対象から外しています。

食い違いは全件が二種類のどちらかです。`non-negotiable` `self-overcoming` `Jean-François`
のように**行末で割れた語を繋ぎ直した**もの、および `( Seelengrund)` `(共同幻想 )` のように
**抽出器が括弧の内側に入れてしまった空白を取り除いた**ものです。それ以外に手を入れた箇所はありません。

```
pip install pypdf==6.19.0
python3 verification/check_fidelity.py       # 上の表が出る
python3 verification/check_fidelity.py -v    # 食い違いを一件ずつ表示
```

本文か PDF のどちらかが変われば落ちます。GitHub Actions が push ごとに実行しています。

抽出器の版が変わっても落ちます。2026-10-10 に pypdf 6.20.0 が出て、断章論の抽出で空白の入り方が変わりました。上の表の数が合わなくなったので、版を 6.19.0 に固定しています。表の数は変えていません。紙面は凍結されているので、動いたのは抽出器のほうです。

## サイトを手元で作る

```
node build.js
```

`site/` に HTML が出ます。Node.js 以外に必要なものはありません。

```bash
node verification/check_keyboard.js
```

ブラウザを起こし、生成した頁を Tab で辿ります。焦点の枠と辿る順を確かめ、広い幅から狭い幅まで、頁が横へはみ出さないかを測ります。文字を 200% にしたときも測ります。playwright と Chromium が要ります。

`verification/check_site.js` は、配色の比（WCAG）、端末の設定に従う暗い配色、画像の代替テキスト、頁の重さ、
頁の下の欄（運営・連絡・免責）、`sitemap.xml` と `robots.txt`、各頁の正の URL も見ます。
サイトは <https://cpsbvbng26-dotcom.github.io/autonomy-and-self-cultivation/> に出ています。
